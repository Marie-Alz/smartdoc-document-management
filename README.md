# smartdoc-document-management-system
A document management system with OCR-based invoice data extraction and approval workflow
SmartDoc is a document management system designed to organize digital documents and simplify invoice processing.
The project aims to extract relevant invoice information using text extraction and OCR technologies, organize documents, and manage approval workflows.
# Planned Features
Upload PDF and image documents
extract text from digital and scanned documents
Identify invoice information such as invoice number, date, supplier, and amount
Categorize and search documents
Manage invoice approval workflows
Review and manually correct extracted information
